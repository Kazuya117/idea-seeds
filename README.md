# アイデアの種

アイデアがあっても一歩を踏み出せない人のための、アイデア共有アプリ（PWA）です。
三田国際科学学園 リベラルアーツのテーマ「アイデアがあっても一歩を踏み出せない人のためのアイデア共有プラットフォーム」の試作版です。

## できること

| 画面 | 内容 |
|---|---|
| みんなの種 | 投稿されたアイデアを見て、4種類の応援スタンプ（いいね・一緒にやりたい・手伝えるよ・もっと聞きたい）を押す。通報もここから |
| 種をまく | 「なにを？」「だれのために？」の2問に答えて投稿する（各140字まで） |
| じぶんの畑 | 自分の植物が並ぶ畑。アイデアごとに「小さな一歩」を決め、水・日光・肥料のたまり具合を見る |
| 管理 | 管理者（生徒チーム）だけに表示。通報された投稿の確認、非表示・再表示・削除 |
| 設定 | ニックネームの変更、ルール、ログアウト |

否定的な反応の手段は置いていません。反応は応援スタンプだけです。

## 見本モード

ログイン画面の「ログインせずに、見本を見る」（または URL の末尾に `?demo` を付ける）で、架空の人・種・応援を使ってひととおりの動きを見られます。じぶんの畑には段階の違う 3 つの種があり、管理タブ（見本では管理者として入る）には通報された投稿と非表示の投稿が 1 件ずつあります。「種をまく」と、数秒後に架空の人が「いいね」を押します。見本の中で押した内容はサーバーに送られず、画面を閉じると消えます（`app.js` の `demoDb`）。

## 育成のしくみ

投稿するときに、育てる植物（ひまわり・チューリップ・さくら・あさがお・たんぽぽ）を選びます。植物は次の3つがそろうと育ちます。

| 要素 | 増え方 | 意味 |
|---|---|---|
| 💧 水 | 自分が一歩を達成する | 行動 |
| ☀️ 日光 | ほかの人から「いいね」「もっと聞きたい」が届く | 共感 |
| 🌿 肥料 | ほかの人から「一緒にやりたい」「手伝えるよ」が届く | 仲間 |

| 段階 | 水 | 日光 | 肥料 |
|---|---|---|---|
| 種 | 0 | 0 | 0 |
| 発芽 | 1 | 0 | 0 |
| 双葉 | 1 | 1 | 0 |
| 若木 | 2 | 2 | 0 |
| つぼみ | 3 | 3 | 1 |
| 開花 | 4 | 5 | 2 |
| 実 | 5 | 8 | 3 |

- 自分で押したスタンプは数えません。
- 応援だけ、一歩だけでは育ちません。行動と共感の両方が必要です。
- 必要な数は `app.js` の `NEED` で変えられます。利用人数に合わせて調整してください。
- 段階はその時点の数から毎回計算します。スタンプが取り消されると、段階が戻ることがあります。

## しくみ

- 画面：ビルド不要の静的サイト（HTML・CSS・JavaScript）。GitHub Pages で配信。
- データ：Supabase（東京リージョン）。プロジェクト `idea-seeds`。
- ログイン：Google ログイン。`@mita-is.ed.jp` のアカウントと、個別に許可したアドレスだけが登録できる。
- 権限：だれが何をできるかは、データベース側（行レベルセキュリティ）で守っている。画面側のチェックは案内のためのもの。

`app.js` に書いてある Supabase のキーは公開用（publishable）で、ページに含めてよい種類のものです。

## 安全のための決まり（データベース側）

- ログインしていない人は何も読めない。
- 他の利用者に見えるのはニックネームだけ。メールアドレスは見えない。
- 投稿は1人1日5件まで。
- 通報が3件たまった投稿は、管理者が確認するまで自動で非表示。
- 自分を管理者にする、他人の投稿を編集・削除する、他人の名義でスタンプを押す、はできない。

## 運営メモ

- 登録を許可するドメイン：`private.allowed_domains`
- 個別に許可するアドレス：`private.allowed_emails`
- 管理者にするアドレス：`private.moderator_emails`（登録時に管理者になる。登録済みの人は `profiles.role` を変更）
- 無料枠の Supabase は、1週間ほど利用がないと一時停止する。再開はダッシュボードから。

## 更新するとき

`app.js` の `VERSION`、`index.html` の `?v=`、`sw.js` の `CACHE` と `?v=` を同じ数字に上げると、利用者の端末に新しい版が届きます。

## まだないもの

- コメント（問いかけ型）
- 仲間が集まったときのお知らせ
- 利用データの集計画面
